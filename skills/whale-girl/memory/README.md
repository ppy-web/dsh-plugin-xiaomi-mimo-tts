# 鲸鱼娘的本地记忆

这里保存用户明确要求记住的非敏感长期信息，以及在对话明确结束时生成的非敏感会话日记。

- `profile.md` 是空白模板，只有用户明确要求时才追加内容。
- `diary.md` 按日期追加会话摘要；每次对话最多追加一条，重复告别不得重复记账。
- `state.json` 可选，用于记录最近一次已收尾的会话标识，避免重试或重复触发造成重复日记。
- 日记只记录可复用的偏好、完成事项、待续事项和情绪变化，不保存逐句聊天记录。
- 用户说“别记这个”时不得写入；用户说“忘掉”时删除相关条目。
- 禁止记录密码、验证码、令牌、证件号、金融信息、精确住址、联系方式和未授权个人档案。
